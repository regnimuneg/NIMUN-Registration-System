📋 Testing Checklist

✅ Step 1: Camera Access

  • Browser shows camera permission prompt
  • Camera feed appears in video element
  • No "Camera denied" errors

🔍 Step 2: QR Detection

  • QR codes are detected automatically
  • Console shows "QR Code detected" messages
  • Scan count increases

🎯 Step 3: Data Parsing

  • QR data is parsed correctly
  • Participant ID is extracted
  • onScan callback is triggered

👤 Step 4: Participant Loading

  • Participant data is fetched from API
  • Tracking tabs become available
  • Success message is shown
